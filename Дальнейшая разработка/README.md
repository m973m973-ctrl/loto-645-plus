## Что уже сделано (эта итерация)

Настольная Windows-версия (`lotto645_app.py`, Python/tkinter):

1. **Весь интерфейс переведён на вкладки** (`ttk.Notebook`):
   `6 из 45 Плюс` · `Инструменты` · `Рейтинг лотерей` ·
   `Проверка прогнозов` · `Русское лото` · `Рапидо` · `4 из 20` ·
   `Жилищная лотерея`.
2. **Исправлена проблема «окно рейтинга не помещается и не скроллится»**:
   рейтинг теперь в прокручиваемом текстовом поле на отдельной вкладке,

   (колесо мыши работает во всех вкладках).
3. **Добавлены 4 лотереи** (выбраны как самые доходные по статистике):
   Русское лото, Рапидо, Спортлото «4 из 20», Жилищная лотерея.
   Для каждой: правила, расписание, статистика, загрузка тиража из API
   Столото и **проверка билета** (алгоритм определения выигрыша — см.
   `Алгоритмы_и_API.md`).
4. **Скачаны архивы тиражей** (в `analysis/`):
   - `archive_ruslotto.json` — Русское лото, тиражи №891–1867
     (глубже API архив не отдаёт);
   - `archive_gzhl.json` — Жилищная лотерея, ПОЛНЫЙ архив №1–727;
   - `archive_4x20.json` — 4 из 20, тиражи №10279–16228 (весь доступный
     объём API);
   - `archive_rapido.json` — Рапидо, последние 4950 тиражей
     (API ограничивает выдачу 100 страницами × 50).
   Формат файлов — в `Алгоритмы_и_API.md`. Докачка свежих тиражей —
   `analysis/download_new_games.py`.
5. Рейтинг лотерей дополнен новыми играми; у «4 из 20» пересчитана
   комбинаторная модель (два поля, 21 выигрышная категория).

## Как проверить настольную версию

```
python lotto645_app.py          # нужен интернет (последние тиражи)
python -m py_compile lotto645_app.py   # быстрая проверка синтаксиса
```

Логика проверки билетов отделена от GUI и тестируется без дисплея:
`bingo_check`, `check_4x20`, `check_rapido` — чистые функции.
