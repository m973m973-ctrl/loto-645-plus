# Алгоритмы определения выигрыша и API Столото

## API Столото (неофициальный мобильный)

```
GET https://www.stoloto.ru/p/api/mobile/api/v35/service/draws/archive?game={КОД}&count=50&page={СТР}
Заголовки:
  User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/150.0 Safari/537.36
  Gosloto-Partner: bXMjXFRXZ3coWXh6R3s1NTdUX3dnWlBMLUxmdg
```

Коды игр (проверены 07.11.2026): `6x45plus`, `6x45`, `ruslotto`
(Русское лото), `gzhl` (Жилищная лотерея), `4x20` (Спортлото 4 из 20),
`rapido` (Рапидо), `podkova` (Золотая подкова), `spec`, `6x36`, `bingo75`.

Ограничения API:
- страница — максимум 50 тиражей;
- пагинация глубже ~100 страниц не отдаёт (пустой ответ/503);
- фактическая глубина архивов: Русское лото — с №891, Жилищная — с №1
  (полная), 4 из 20 — с №10279, Рапидо — последние ~4950 тиражей;
- при 503 — пауза 1–2 с и повтор.

## Форматы архивов в `analysis/`

Все — массив JSON, отсортирован по номеру тиража `n`.

- `archive_ruslotto.json`, `archive_gzhl.json`:
  `{n, d, sp, np, r, wm}` — дата, суперприз, `np` = НЕвыпавшие бочонки,
  `r` = бочонки каждого тура (списки, по порядку туров),
  `wm` = [сумма приза, число победителей] по турам.
- `archive_4x20.json`: `{n, d, sp, a, b}` — `a` = 4 числа поля 1,
  `b` = 4 числа поля 2.
- `archive_rapido.json`: `{n, d, sp, p, par}` — `p` = 8 чисел поля 1 +
  1 число поля 2 (9-й элемент), `par` = чёт/нечет.
- `archive_full.json`: только Спортлото «6 из 45 Плюс» (`game=6x45plus`),
  `{n, date, main, plus, w4, cols}`; `main` = 6 чисел, `plus` = 1 число 1–4.
- `archive_6x45.json`: только классическая Спортлото «6 из 45»
  (`game=6x45`), отдельная игра без плюс-шара. Её тиражи нельзя объединять
  с архивом Плюс по номеру тиража: нумерация у игр независимая.

## Алгоритмы определения выигрышной комбинации

### 6 из 45 Плюс
Совпадения основного поля: `k = |комбинация ∩ тираж.main|`; второе поле
сравнивается отдельно с `тираж.plus`. Приз есть за 2–5 основных совпадений
независимо от плюс-шара. Полная основная шестёрка даёт:
- `6+0` — отдельную призовую категорию (не суперприз), вероятность
  `3 / (4 × C(45,6))`;
- `6+1` — суперприз, вероятность `1 / (4 × C(45,6))` = **1 : 32 580 240**.

Шанс **1 : 8 145 060** относится только к угадыванию шести основных чисел
(и к суперпризу классической «6 из 45»), но не к суперпризу Плюс.

### Русское лото и Жилищная лотерея (бинго, 90 бочонков)
Билет: 2 поля × 3 строки × 5 чисел (30 чисел из 90). Функция
`bingo_check(rows6, draw)` в `lotto645_app.py`:

1. Тур 1: любая строка (5 чисел) ⊆ бочонки 1-го тура.
2. Тур 2: любое поле (15 чисел) ⊆ бочонки туров 1+2.
3. Тур 3: все 30 чисел ⊆ бочонки туров 1+2+3.
4. Туры 4+: каждая категория = 1 ход; билет выигрывает в первом туре,
   где все 30 чисел закрыты кумулятивно.
5. ДЖЕКПОТ: поле (15 чисел) ⊆ первые 15 бочонков (комбинаторно
   1 : C(90,15)/2 ≈ 1 : 22,9 квадриллиона).

Билет выигрывает один раз — в самом раннем туре.

### Спортлото «4 из 20»
`check_4x20(f1, f2, draw)`: `a = |f1 ∩ тираж.f1|`, `b = |f2 ∩ тираж.f2|`.
Выигрыш при `a >= 2` или `b >= 2` — всего 21 выигрышная категория
(все пары (a,b) кроме 0+0, 0+1, 1+0, 1+1). Суперприз: 4+4
(1 : 23 474 025).

### Рапидо
`check_rapido(f1_8, f2_1, draw)`: `a` = совпадения в поле 1 (0–8),
`b` = попадание в поле 2 (0/1). Классическая таблица: выигрыш от «4+1»
и «5+0» и выше (9 категорий); суперприз — 8+1. Суммы призов — по
`winningCategories` конкретного тиража из API.

## Прогнозные алгоритмы 6/45 (уже были в проекте)

- **Статистическая**: 3 числа из горячих за 100 тиражей + 2 из давно не
  выпадавших + 1 из лидеров за всю историю.
- **Запасная**: зеркально — 3 из «просроченных» + 3 из горячих.
- **Антитолпа**: числа, которые реже всего отмечают игроки (оценка по
  доле победителей категории «4 из 6» в тиражах, где число выпадало и
  не выпадало); при выигрыше приз делится между меньшим числом людей.
- Все стратегии проходят walk-forward бэктест
  (`analysis/strategy_backtest.py`): шансы не повышаются — это честно
  указано в приложении.

## Докачка свежих тиражей

```
python analysis/download_new_games.py ruslotto analysis/archive_ruslotto.json
```
Скрипт дедуплицирует по номеру тиража и дописывает только новое.
