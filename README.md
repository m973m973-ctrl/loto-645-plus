# Лото 6 из 45 Плюс — статистика тиражей

Приложение для анализа архива тиражей лотереи «6 из 45 Плюс» (Столото).
Две версии: настольная для Windows (Python/tkinter) и мобильная для Android (Kotlin).

## Возможности

- Последний тираж, горячие и давно не выпадавшие числа, частотный график.
- Три прогнозные комбинации: статистическая, запасная, «антитолпа»
  (числа, редко отмечаемые игроками, — при выигрыше меньше делить приз).
- Бэктест каждой комбинации по полной истории обеих игр (28 000+ тиражей).
- Журнал проверки прогнозов: последние 100 тиражей, цветная подсветка
  совпадений, фильтр «только 2+ совпадения».
- «Мои комбинации»: сохранение своих наборов, автопроверка по каждому
  новому тиражу, статистика призовых совпадений за 100 тиражей.
- Генератор «антитолпа»-билетов.
- Калькулятор развёрнутой ставки и синдиката (комбинации, стоимость, шансы).
- Android-версия: виджет рабочего стола с последним тиражом и совпадениями
  ваших комбинаций.
- Автообновление данных с публичного архива stoloto.ru.

## Честное предупреждение

Все комбинации равновероятны (1 : 8 145 060). Статистика не повышает шанс
выигрыша — проверено walk-forward бэктестом стратегий на всём архиве
(`analysis/strategy_backtest.py`). Приложение не является азартной игрой,
не принимает ставки и не связано с оператором лотереи.

## Сборка

Windows (exe):

```
pyinstaller --noconfirm Loto645Plus.spec
```

Android (apk):

```
cd android_loto
gradlew.bat assembleDebug
```
